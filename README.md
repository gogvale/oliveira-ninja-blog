# oliveira.ninja blog

Jekyll + Chirpy source for [blog.oliveira.ninja](https://blog.oliveira.ninja).

This repository was created from
[cotes2020/chirpy-starter](https://github.com/cotes2020/chirpy-starter).

## Development

```bash
bundle install
bundle exec jekyll serve
```

## Deployment

GitHub Pages deploys this site through the included GitHub Actions workflow.
The custom domain is configured through GitHub Pages settings/API, not through a
committed `CNAME` file.

Current domain target: `blog.oliveira.ninja`.
